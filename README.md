## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/langchain_learning.git
cd langchain_learning

# 创建虚拟环境
conda create -n langchain_learning python=3.12 -y
conda activate langchain_learning

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
